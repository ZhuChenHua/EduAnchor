# 机器学习基础（示例教材）

<!-- page: 1 -->

## 第1章 机器学习概述

机器学习是研究如何让计算机从数据中自动获取规律，并利用规律对未知数据进行预测的一门学科。更正式地说，机器学习是指通过经验改善系统性能的过程，其中经验通常以数据的形式出现。与传统程序设计依赖人工编写规则不同，机器学习方法从训练数据中归纳模型，再将模型应用于新样本。

按照学习任务所利用的数据形式，机器学习通常分为监督学习、无监督学习和强化学习。监督学习使用带标签的数据，目标是学习从输入到输出的映射；无监督学习只使用无标签数据，目标是发现数据内部的结构，例如聚类和降维；强化学习则通过智能体与环境的交互获得奖励信号，学习能够最大化长期回报的策略。

一个完整的机器学习流程通常包括问题定义、数据收集与清洗、特征工程、模型选择、模型训练、模型评估和部署上线。教材强调，模型评估必须使用与训练数据独立的数据，否则评估结果会偏乐观，无法反映模型在真实场景中的表现。

## 第2章 监督学习基础

在监督学习中，训练数据由输入样本和对应的标签组成，通常记为 $(x_i, y_i)$。模型的目标是学习一个函数 $f(x)$，使得 $f(x_i)$ 尽可能接近 $y_i$。当标签为离散类别时称为分类任务，当标签为连续数值时称为回归任务。

损失函数用于度量模型预测值与真实标签之间的差异。常见的损失函数包括用于回归的均方误差和用于分类的交叉熵。经验风险是训练集上损失函数的平均值，最小化经验风险是训练模型的常见目标。然而，经验风险最小并不等于泛化能力最好，因为模型可能记住了训练样本的噪声。

泛化是指模型在未见数据上的表现。教材将泛化误差分解为偏差、方差和不可约误差三部分。偏差反映模型假设与真实规律的偏离程度，方差反映模型对训练集扰动的敏感程度。模型过于简单会导致高偏差，称为欠拟合；模型过于复杂会导致高方差，称为过拟合。

## 第3章 模型评估与选择

为了客观评价模型，数据集通常划分为训练集、验证集和测试集。训练集用于学习参数，验证集用于选择超参数和比较模型，测试集只在最终评估时使用一次。当数据量较小时，可以使用 k 折交叉验证：将数据分成 k 份，轮流用其中一份作为验证集，其余作为训练集，最后对 k 次结果取平均。

分类任务常用混淆矩阵计算指标。准确率是预测正确的样本数占总样本数的比例。精确率是预测为正的样本中真正为正的比例，召回率是真正为正的样本中被预测为正的比例。精确率和召回率往往存在权衡，F1 分数是二者的调和平均，用于综合衡量分类性能。

过拟合的常见缓解方法包括增加训练数据、降低模型复杂度、使用正则化、早停和集成学习。L2 正则化在损失函数中加入参数平方和，使模型参数趋向于较小的值；L1 正则化加入参数绝对值之和，能够产生稀疏参数。正则化强度由超参数控制，需要在验证集上选择。

## 第4章 决策树与集成学习

决策树是一种基于树结构进行决策的模型。每个内部结点表示对某个特征的测试，每个分支表示测试结果，每个叶结点表示预测结果。构建决策树的关键是选择划分特征，常用的准则包括信息增益、信息增益率和基尼指数。

信息熵用于度量随机变量的不确定性。熵越大，不确定性越高。信息增益是划分前后信息熵的差值，表示某个特征为分类带来的信息量。教材指出，信息增益偏向于取值较多的特征，因此可以使用信息增益率进行修正。

决策树容易过拟合，需要通过剪枝控制复杂度。预剪枝在树生长过程中提前停止分裂，后剪枝先生成完整树再自底向上裁剪。集成学习通过组合多个基学习器提升性能。随机森林在样本和特征两个层面引入随机性，训练多棵决策树并投票，因此比单棵决策树更稳定、方差更低。梯度提升则按顺序训练弱学习器，每一轮拟合前一轮的残差，逐步降低损失。

## 第5章 神经网络基础

感知机是最简单的神经网络模型，它对输入进行加权求和并通过符号函数输出类别。单层感知机只能解决线性可分问题，多层神经网络通过非线性激活函数获得拟合复杂函数的能力。常见激活函数包括 Sigmoid、Tanh 和 ReLU。ReLU 计算简单，在正区间梯度恒为 1，能够缓解梯度消失问题。

反向传播是训练神经网络的核心算法。它利用链式法则从输出层向输入层逐层计算损失函数对参数的梯度，再配合梯度下降更新参数。梯度下降的更新幅度由学习率控制。学习率过大会导致训练震荡甚至发散，学习率过小会使收敛速度过慢。实际训练中常使用自适应学习率方法或学习率衰减策略。

神经网络训练还需要考虑批大小、迭代轮数、参数初始化和正则化等因素。批大小影响梯度估计的噪声和内存占用；迭代轮数过多可能导致过拟合；合理的参数初始化有助于稳定训练。教材强调，实验配置应当完整记录，以保证结果可复现。

## 第6章 自然语言处理与教材问答

自然语言处理研究如何让计算机理解和生成人类语言。文本进入模型前通常需要分词。中文分词将连续汉字序列切分为词语，常见方法包括基于词典的方法、基于统计的方法和基于深度学习的方法。词向量将词语映射为稠密向量，使语义相近的词在向量空间中距离更近。

注意力机制让模型在处理某个位置时动态关注输入中的其他位置。自注意力通过计算查询、键和值之间的相关性，得到加权表示。Transformer 以自注意力为核心，成为大语言模型的基础结构。预训练语言模型在大规模语料上学习通用语言表示，再通过微调或提示适配下游任务。

检索增强生成（RAG）将外部知识检索与文本生成结合：系统先根据问题检索相关文档片段，再把片段作为上下文交给生成模型。RAG 能够降低模型幻觉，但效果依赖检索质量与上下文组织。教材锚定是一种面向教育场景的约束策略，它要求回答必须能够追溯到教材原文，并在教材未覆盖时明确拒答。大语言模型产生幻觉的常见原因包括训练知识过期、缺乏领域证据以及生成目标鼓励流畅而非真实。通过原文引用、支撑检查和超纲拒答，可以显著提升教育问答的可信度。
