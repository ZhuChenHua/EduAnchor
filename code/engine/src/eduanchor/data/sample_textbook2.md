# 概率统计与模型评估示例教材

<!-- page: 1 -->

## 第1章 概率基础

概率论用数值刻画随机现象。随机试验所有可能结果组成的集合称为样本空间，记作 Ω；样本空间的子集称为随机事件。事件 A 发生的概率 P(A) 满足非负性、规范性和可列可加性。古典概型假定每个基本结果等可能，此时事件概率等于有利结果数除以基本结果总数。

条件概率描述在事件 B 已发生的条件下事件 A 发生的可能性，定义为 P(A|B)=P(AB)/P(B)，其中 P(B)>0。若 P(AB)=P(A)P(B)，则称事件 A 与 B 相互独立。全概率公式把一个事件按互斥且完备的原因分解：若 B1,…,Bn 两两互斥且并为 Ω，则 P(A)=ΣP(A|Bi)P(Bi)。

贝叶斯公式由条件概率和全概率公式推出：P(Bi|A)=P(A|Bi)P(Bi)/P(A)。它把先验概率 P(Bi) 与似然 P(A|Bi) 结合，得到后验概率。贝叶斯公式常用于根据新证据更新对某个假设的信念，但后验结果依赖先验设定。

## 第2章 随机变量与常见分布

随机变量是把样本空间映射到实数的函数。离散随机变量用概率质量函数描述，连续随机变量用概率密度函数描述。期望 E[X] 表示随机变量的长期平均水平，方差 Var(X)=E[(X-E[X])^2] 表示取值围绕均值的离散程度。标准差是方差的算术平方根，与随机变量同量纲。

伯努利分布只取 0 和 1 两个值，若成功概率为 p，则 E[X]=p，Var(X)=p(1-p)。二项分布表示 n 次独立伯努利试验中成功次数，其期望为 np，方差为 np(1-p)。正态分布由均值 μ 和方差 σ² 完全确定，记作 N(μ,σ²)；标准正态分布是 μ=0、σ²=1 的特例。

正态分布在统计中重要，是因为许多独立随机变量之和近似服从正态分布，这由中心极限定理保证；因此样本均值在大样本下常可用正态分布近似。使用正态近似时要注意样本量和分布偏斜程度，极端分位数或强相关数据不宜直接套用。

## 第3章 参数估计

参数估计根据样本推断总体参数。点估计给出一个具体数值，区间估计给出一个包含参数的概率区间。最大似然估计选择使观测样本出现概率最大的参数值；连续情形通常最大化对数似然，因为对数不改变极值位置且便于计算。

最大后验估计在似然之外加入先验分布，最大化后验概率。它与最大似然估计的区别在于是否使用先验信息：当先验较平坦或样本量较大时，两者结果往往接近；当先验较强或样本较少时，差异可能明显。

估计量是被估计参数的随机变量。无偏估计的期望等于真实参数；有偏估计的期望与真实参数存在系统偏差，但偏差小、方差低的估计量在预测任务中仍可能更有用。置信区间是在重复抽样下以给定覆盖率包含真实参数的区间，95% 置信区间不表示真实参数有 95% 的概率落在某一次算出的区间内。

## 第4章 假设检验

假设检验先提出原假设 H0 和备择假设 H1，再利用样本判断是否有足够证据拒绝 H0。原假设通常表示没有差异或没有效应，备择假设表示研究者希望支持的结论。检验统计量在 H0 成立时服从某个参考分布。

p 值是在原假设成立时，得到当前样本或更极端结果的概率。p 值不是原假设为真的概率，也不是效应大小。显著性水平 α 是事先设定的拒绝阈值；当 p<α 时拒绝原假设。α 越小，拒绝原假设的门槛越严格。

第一类错误是原假设为真却被拒绝，其概率上限由 α 控制；第二类错误是原假设为假却没有被拒绝。检验功效是正确拒绝错误原假设的概率，等于 1 减去第二类错误概率。增加样本量、提高效应量或降低噪声通常能提高检验功效。

## 第5章 线性回归与正则化

线性回归用输入特征的线性组合预测连续目标。最小二乘法选择使残差平方和最小的参数，残差是观测值与预测值之差。最小二乘估计有解析解，但特征高度相关或样本量小于特征数时，解可能不稳定。

正则化在损失函数中加入参数惩罚，以控制模型复杂度。岭回归使用 L2 惩罚，即参数平方和，倾向于把参数整体缩小；Lasso 使用 L1 惩罚，即参数绝对值之和，能够把部分参数压到零，从而产生稀疏解。正则化强度由超参数控制，需要在验证集上选择。

模型在训练集上误差小并不代表泛化好。训练误差过低而验证误差升高通常是过拟合的信号；正则化、减少特征、增加数据或早停都可以缓解过拟合。选择模型时应同时观察训练误差和验证误差，而不是只看训练集表现。

## 第6章 模型评估与交叉验证

为了客观评估模型，数据通常划分为训练集、验证集和测试集。训练集用于拟合参数，验证集用于选择超参数和比较模型，测试集只在最终评估时使用一次。若反复用测试集调参，测试结果会偏乐观。

k 折交叉验证把数据分成 k 份，每次用其中一份作为验证集，其余 k-1 份作为训练集，重复 k 次后取平均。分层 k 折交叉验证在每折中保持类别比例，适合类别不平衡的数据。交叉验证能降低单次划分带来的偶然性，但计算成本随 k 增加。

分类任务常用准确率、精确率、召回率和 F1 分数。准确率是预测正确的样本占全部样本的比例；精确率是预测为正的样本中真正为正的比例；召回率是真正为正的样本中被预测为正的比例。精确率和召回率存在权衡，F1 分数是二者的调和平均。

ROC 曲线以假正率为横轴、真正率为纵轴，描述分类阈值变化时的取舍；AUC 是 ROC 曲线下面积，取值越接近 1 表示排序能力越强。类别不平衡时，准确率可能被多数类主导，例如负类占 95% 时全部预测为负也能得到 95% 的准确率，因此应同时报告精确率、召回率和 AUC。
